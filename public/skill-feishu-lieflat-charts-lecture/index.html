Definition · Skill

Skill 是给 AI Agent 的一份
可安装作业手册。

它告诉 Agent：什么时候接手、按什么流程做、可以调用什么，以及做到什么才算完成。

可安装 · 可触发 · 可执行 · 可验收
Mental Model04 / 22
Mental Model

四个概念，不要混成一锅粥

Skill 不是工具本身，而是组织工具、规则和资源的方法。

Prompt

这一次想做什么？

“把这份飞书数据做成图表。”

Skill

以后怎样稳定完成？

可复用的组合工作流。

Tool / CLI

具体靠什么执行？

飞书 CLI 读取多维表格。

MCP

怎样连接外部工具？

今天只点到为止，不展开协议。

Prompt ≠ Skill ≠ Tool ≠ MCPKeep Them Apart
Decision Gate05 / 22
Decision Gate

什么工作，值得做成 Skill?

当一件事重复发生、有固定规则、普通 Prompt 经常漏步骤，而且结果能够验收。

  • 每周或每月反复发生
  • 依赖同一套业务规则
  • 需要真实工具、数据或模板
  • 有明确完成标准
  • 需求尚未想清时，先别堆说明
Repeat · Rules · Tools · AcceptanceWorth Automating?
Anatomy06 / 22
Anatomy

一个最小 Skill，只需要一个文件

文件不是越多越专业。能用一个 SKILL.md 讲清，就先别开文件夹杂货铺。

├── SKILL.md — 触发、流程、边界、验收
├── references/ — 详细规则，需要时再读
├── scripts/ — 重复且易错的机械动作
└── assets/ — 交付时复用的模板和素材

Step 05 · Guardrails18 / 22
Step 05 · Guardrails

真正的含金量，在边界和验收里

Boundary

不能乱做什么

  • 不猜 token、表名、字段和口径
  • 不泄露 Secret、令牌和真实数据
  • 默认不删除、更新或改仪表盘
  • 结果不完整，不下全局结论
Done

怎样才算完成

  • 表、字段、筛选与时间可追溯
  • 图表直接回答管理问题
  • HTML 可以正常打开
  • 结论与图中数值一致
