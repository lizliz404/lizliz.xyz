01 / 主要矛盾

先验证代建能否在可控工时内成交

按原始沟通，Foundry 的基础交付是：客户提供货盘和产品资料，得到带后台、后续可运营的外贸询盘站。价值不止是第一次上线，还包括之后更新产品和内容。翻译、AI 洗图、随业务扩展后台是提出的方向；AI 接待和数据导出也需要逐项核验，未核验的功能不进入销售承诺。

自助市场已有 ¥500/年的 AllinCMS，并配有拼团、推荐奖励和退款机制5，只讲“AI 建站”不足以解释客户为什么选我们。代建可以卖资料整理、上线和有人负责，但也增加售前沟通、修改和维护工时。先做一单范围明确的样板，比同时铺开三个档位更容易验证这笔生意。

先把每个购买对象能拿到什么、要花多少工时说清楚，再谈价格。

02 / 客户

三个待验证的购买情境

以下是建议先测试的三种情境，不是已经验证的客户画像。优先找同时满足“资料已备好、能接触海外买家、愿意自己维护”的人；咨询时核对近期要解决什么、谁拍板、现用方案和预算。

  • 有货盘、有 PDF 或 Excel 目录，现有的站改不动，或者没有站。适合验证：客户愿不愿为资料整理、首次上线和后台交接付费。
  • 已经在阿里国际站或中国制造网付年费，续费时在算账。他要第二个入口，和可预测的费用。
  • 有固定的海外客户来源——展会、老客户、领英——缺落地页。他要交付速度和完成度。

客户需要的承诺，与不能当作独有优势的能力

建议用交付证明

  • 后台常规改动由客户自己完成；新增开发另定范围
  • 维护到期后可降为付费自助档；与 ZanCms 不续费即下线的条款有区别7
  • 资料齐后多久能上线：由样板单计时，再确定交期

不能当独有优势

  • 资产归客户、数据可导出：星谷云公开承诺数据所有权与到期导出8，ONEW 也写代码可交付10
  • GEO 与 AI 搜索推荐：Durable、AllinCMS 在低价档就在讲13
  • 「AI 建站」本身：是交付手段，不是卖点

星谷云的归属与导出是官网承诺，不是本次试用结果。Foundry 目前可先落实“域名在客户名下和账户里”；数据导出、迁移范围要验收后再写进合同。

不适合的人

要询盘数或排名保证的；要代投广告、外链 SEO 的；要源码级定制或多语言深度开发的；只买最低价的。这条清单应该放进对外内容里，省下的是销售时间。

03 / 三个购买对象

一次性交付、自助工具、一段时间的服务

A 卖工具，B 卖一次交付，C 卖一段时间。计量单位不同，客户很容易拿最便宜的那个来比价——先把这层说清，再谈数字。

A / 自助 原始口径

¥500 开站

客户自己建、自己改。

  • 带后台的站、托管、SSL、询盘收集
  • 绑定客户自己的域名
  • 方案建议先看草稿再付费，开放方式待确认

不含人工。¥50/月与首年约 ¥1,050 是方案里的另一提法，续费方式未确认。

B / 代建 · 主推 拟议

¥5,800 起，含 3 个月维护

目标 ≤8 小时/单，尚无实测。

  • A 档全部，加资料与产品整理（≤50 SKU，拟议上限）、1 轮设计调整
  • 代买域名，注册在客户名下
  • 询盘推到企业微信或邮箱，每月 1 次内容更新

不含：50 SKU 以上、第 2 轮设计、文案、拍图、广告、外链。

C / 持续服务 拟议

¥1,500–2,000 / 月，按季

在建站费之外收取，按季度签约。

  • 每期一张写死清单；每月上新 20 个、修改 4 次是原提案估算，上限待实测
  • 询盘分拣，每月一份月报

季度续约、提前 30 天通知是原提案，不是生效条款。不含重 SEO、外链、广告代投、社媒代运营；不承诺询盘数、排名、流量。

建议售前只做首页或约定页面，并记录草稿工时；完整建站、设计调整、维护分别写清范围。清单外需求先确认费用和交期，再开工。AIGA 合同范本提供变更单和验收期的参考11，具体合同及“5 个工作日未反馈视为验收”等条款应请律师确认，不自动照搬。

到期与域名

降回 A 档继续在线的前提是客户还在付 A 的费用；完全不付费时的保留期与导出规则还没有定，现在不承诺。域名按能落实的方式做：客户自己开注册商账户、自己付年费，我们被授权代买和改 DNS，不能转出。候选是 Porkbun 的授权用户，API 能否代操作待实测；备选 Cloudflare Registrar，代价是 DNS 绑在 Cloudflare 上。"内容和数据可导出"要先核对功能，再写进合同。

05 / 获客

接触、咨询、合格草稿、付费

只记这四个数。每个渠道一行账，含投入时间和投入现金；浏览量和点赞不进这张表，它们不能证明生意跑通。

  1. 接触一对一触达：转介绍、社群、私信、线下。
  2. 咨询对方主动问价格或流程。
  3. 合格草稿开始建，且资料真的到位。
  4. 付费钱到账，按渠道记。

顺序

1. 暖渠道：老客户、熟人、外贸培训老师、群主、服务商。AllinCMS 用 ¥100 红包或 2 万点招募这批人5——这只能说明有人在这么做，不能证明对我们有效，要自己记账。

2. 一条 60–90 秒录屏：丢进 PDF 目录 → 出站 → 当场改一个参数 → 发布 → 询盘推到企业微信。同一条素材给个人号、公众号和分销用，只拍已经上线的功能。

3. 搜索型内容：公众号、小红书、百度、豆包，同一批 FAQ 一稿多用。小红书不能在笔记、评论或私信里留微信电话，线索走官方留资工具。

4. 分销最小版：3 个人、按档计佣、统一价、专属链接判归属、钱进我们账户。保证金、区域保护、独家都不做。

承接和底线

承接做轻：在对客页面、账号主页、名片和报价单上，使用同一个微信二维码和邮箱；按平台当期规则展示。这是内部讨论页，不放联系方式占位或客服系统。

暂缓付费投放：先确认哪个客户愿意买、能接受什么范围，再决定是否花钱放大。名额根据可投入工时设定，阶梯价如采用，条件须公开且真实；效果宣传需要真实数据和适用范围，不能靠一句免责声明代替证据。

06 / 单位经济

先算贡献，再谈毛利

¥5,800 是原方案的拟议价格，8 小时是目标，不是实测。先看收入对工时有多敏感，再扣除全部获客与履约成本。

¥5,800 ÷ 8 小时（交付目标，不含维护与获客） ≈ ¥725 / 小时
¥5,800 ÷ 12.5 小时（8 交付 ＋ 1.5 维护 ＋ 3 获客） ≈ ¥464 / 小时
¥5,800 ÷ 18.5 小时（14 交付 ＋ 1.5 维护 ＋ 3 获客） ≈ ¥314 / 小时

三个分母分别是"只算交付目标""目标工时加维护与获客""交付超出到 14 小时"。1.5 与 3 小时是占位假设；三个数都只是敏感性算例，不是工时实测，也不是毛利。

真正要填的是这张模型：贡献 ＝ 收入 − 获客现金 − 分销佣金 − 托管、支付、域名等直接成本 −（获客 ＋ 交付 ＋ 维护工时）× 团队内部时薪 − 退款与返工准备。内部时薪由你们定，填进去才知道每个客户留下多少；在此之前，任何"毛利率"都是编的。

C 档的容量账

按原提案的拟议上限——同时 5 家、每家每月 4 小时——是 20 小时/月，对应 ¥7,500–10,000/月收入，尚未扣成本。招聘平台上一年以下经验运营的标价约 ¥9,885/月，且不含雇主额外负担12。低端收入甚至未覆盖这份工资，因此不能仅凭“已有五个客户”就决定招全职；先验证留存、工作量和完整用人成本。

现金和失败条件

预收款含未交付的义务，收入应按服务发生的期间确认，具体口径问会计；退款按合同。三种情况出现时，先改范围或价格，不靠加班消化：交付超出报价所含的工时；实际获客成本高于可承受值；清单外请求频繁出现。

路线并非只能选 B：如果客户能独立上线、支持成本很低，可以优先自助；如果需求差异大且愿付更高价格，可以转项目制报价；持续服务则另测客户续费意愿。先测代建，是因为原始沟通中已有一个希望人工搭建与维护的客户线索，验证路径更短。

07 / 下一步

先把工时拿到，再定价格

建议用下面的四周顺序推进；分工和日期待两人确认，D 为启动日。第 4 周同时检查下一笔付费与样板单工时：有付费且成本可接受，再扩大同一渠道；有咨询无成交，查客户、演示和报价；交付超时，先缩范围或提价。

  1. 问清新加坡这单

    预算币种、站点范围、维护期限，三件事书面确认。币种不同量级差数倍，先问清再引用任何海外参考价。

    建议 Hanzi · D+3
  2. 交付并分段记工时

    资料整理、建站、设计调整、发布、维护，每段都要有实际小时数。

    建议 Hanzi · D+10
  3. 跑一遍域名流程

    客户开账户、加授权、代买、改 DNS。顺手问清客户站托管在哪。

    建议 Hanzi ＋ Liz · D+10
  4. 一条录屏，加十个一对一

    录屏只用已上线功能；十个接触对象全部写进渠道账，包括被拒绝的。

    建议 Hanzi ／ Liz · D+14
  5. 用实测工时回填范围与价格

    B 的 SKU 上限、C 的清单数量、名额与阶梯，等到这天再定。

    建议两人 · D+21
  6. 一页纸合同骨架给律师

    范围、变更单、验收、退款；顺带问长期合作者是否构成劳动关系。

    建议 Liz · D+21

待定项

  1. B 的价格与工时目标按 ¥5,800 起、≤8 小时走，SKU 上限仍用 50，超出单独报价。
  2. 新加坡这单报多少先确认预算币种与范围再谈价；S$1,980 只是原方案的海外参考价，不是这单的报价。
  3. A 档续费口径先确认 ¥500 包含什么，再决定月付或年付；对客只保留一套明确的费用说明。
  4. C 每期上多少、改几次先按原提案的每月 20 个 / 4 次，样板单之后再调。
  5. 名额和阶梯价公开吗先公开名额数量、不做倒计时；阶梯等工时数据再定。
  6. 域名用哪家看客户站托管在哪：在 Cloudflare 就用它，否则用 Porkbun。
  7. 正式分销做不做先只跑转介绍（¥300/单，拟议），确认有人持续推荐再谈佣金体系。
