问题不是怎么把站卖便宜。

问题是：头几十个付费客户从哪里来，同时不让高接触服务吃光两个人的时间？

我们的解法

代建收钱，也喂产品

每单记工时、记重复动作。重复 ≥3 次的工作，考虑做成模板或后台功能。

展开：Foundry 卖的到底是什么？

不只是做一个展示网站。客户有货盘，Foundry 帮他搭一个带后台的外贸站，之后还能自己更新产品、调整页面和处理询盘。

lhz 提出的长期方向是让后台随业务迭代，并嵌入翻译、AI 洗图等工作流。哪些已经可用、哪些仍是方向，做演示前逐项核对。

客户为什么要买：自己做省钱但费时间；找人代建省时间；持续代运营则是购买持续服务。先看成品降低首次购买的不确定性。

03 / 三档

自助打底，代建主推，代运营限量。

三档是同一条客户路径：自己做 → 帮你做 → 持续帮你运营。

A / 自助

客户自己做

¥1,050 首年

¥500 开站（含首月）+ ¥50/月；人工服务不包含。

  • AI 建站、后台、托管、SSL、询盘收集
  • 客户自己的域名；免费草稿，看到成品再付
  • 年付 ¥500 为待定假设
B / 主推

我们帮客户建

¥5,800 起

含 3 个月维护。≤8 小时/单是目标假设，要用样板单实测。

  • ≤50 SKU、1 轮设计调整
  • 每月 1 次内容更新，询盘推企微或邮箱
  • 客户名下域名；到期转 C 或降回 A，继续在线
C / 限量

持续帮客户运营

¥1.5–2k /月起

在建站费用之外，按 3 个月一期；自动续期，提前 30 天可通知不续。

  • 每期明确工作清单；清单外另报价
  • 询盘分拣、每月一份月报
  • 不承诺询盘数、排名或流量
注意：B 到期“不下线”指降回 A 继续在线，不是免费永久托管。A、B、C 的计量单位不同，如何报价仍待拍板。
展开：范围、产能和阶梯价

B 不含第 2 轮设计、超出 50 SKU、文案、拍图、广告和 SEO 外链。C 不含重 SEO、外链、广告代投和社媒代运营；每月上新 20 个、修改 4 次只是待实测假设。

名额和台阶均为假设：B 本季 6 单：前两单 ¥5,800，第 3–4 单 ¥6,800，第 5–6 单 ¥7,800；C 同时最多 5 家：¥1,500 / ¥1,800 / ¥2,000 每月。稀缺必须来自真实产能；满了排队或扩产，不做假倒计时。

海外 B 参考 S$1,980；新加坡样板单币种和范围仍需问清。C ≤4 小时/月/家、B ≤8 小时/单均需实际验证。

展开：客户资产和域名

建议使用客户自己的账户和域名，客户直接支付域名费；B、C 由我们协助购买和配置。Porkbun Authorized User 是候选方案，API 权限尚待实测；Cloudflare Registrar 是备选，取决于托管位置。

“内容和数据可以导出”能否承诺，必须先核对现有功能。资产归属是客户需求，但不是我们独有的差异点。

先看再付

04 / 复购

留下来

B 到期选 C 或回 A；C 用交付记录与月报说明价值。

展开：先做哪些渠道，不做哪些？

优先：微信生态；分销和熟人转介绍；小红书搜索型内容；FAQ 一稿多用。分销先试 3 人：统一价格、按档计佣、专属链接判归属，钱进入我们账户。

暂不做：无转化数据前不投广告、不拍品牌宣传片、不主动开拓海外；海外先接转介绍。小红书按平台规则使用官方留资方式，不在笔记、评论或私信留微信。

60–90 秒内容主线：丢 PDF → 出站 → 改参数 → 发布 → 询盘推送。具体能力和流程需先实测，不能把待实现的内容拍成已经实现。

05 / 四周验证

先跑一轮，用结果说话。

重点不是把计划写满，而是拿到真实成交、交付工时和渠道数据。

01 / 样板单

新加坡项目做成 B 档样板

先问清币种与范围，记录工时、客户原话和重复动作；留存可授权使用的案例素材。

02 / 渠道实验

3 个渠道，各测两周

分销、个人号与品牌号内容、熟人转介绍。记录私信数 → 建草稿数 → 付费数，再比较保留谁。

03 / 内容与产品

拍一条演示，记一张表

一条 60–90 秒录屏兼作内容与分销素材。每月挑出重复 3 次以上的动作，评估产品化。

04 / 交付边界

合同过律师，域名走一遍

确认范围、变更、验收和劳动关系；用样板单实测客户账户、授权、买域名与 DNS 的流程。

检验标准：有没有付费、每单到底花多少时间、哪个渠道真正带来客户。
把账算清

¥5,800 能不能撑住交付？

按目标 8 小时粗算，收入约 ¥725 / 小时；这是交付前的收入，不是利润，还没扣获客、维护、域名、税费和其他成本。记录实际工时再判断能否规模化。

看漏斗，不看热闹

哪个渠道真正带来付费？

每条渠道分别记：接触 → 咨询 → 草稿 → 付费，再对照投入的时间与费用。小样本先看真实客户反馈，不把浏览量当成交。

展开：最容易踩的坑
  • 时间被预售：C 按季、清单写死、记录工时；A 明确不含人工。
  • 范围蔓延：清单外走变更单；验收与修改轮次写进合同。
  • 效果纠纷：只承诺交付，不承诺询盘数、排名或流量。
  • 能力错配：目前不承诺 AI 接待询盘；只按现有能力承诺推送到企微或邮箱。
  • 内容与渠道：核实素材权利、避免误导性效果或虚假稀缺；渠道统一价格。
06 / 需要拍板

这次讨论，先定什么？

以下是方案里的开放问题，不把讨论稿包装成已经决定的事。

01B 档：¥5,800 起和 ≤8 小时/单的目标，是否接受？样板单超时怎么办？
02C 档：每期上新 N 个、修改 M 次，具体定多少？清单外怎么报价？
03名额：B 6 单、C 5 家和阶梯价格只是示意；真实产能及公开方式是什么？
04客户资产：托管在哪里？域名选 Porkbun 还是 Cloudflare？数据和内容是否真的能导出？

06扩产与样板：何时招人、兼职还是全职？新加坡这单的币种、范围和报价是什么？
