# 货盘没有英文：外贸黑话的英语生存指南

做外贸第一周，你大概率会碰到这个场景：

客户在 WhatsApp 上问：*Can you send me your full catalog?*

你心想：他要看货盘。

然后你打开翻译软件，输入「货盘」，得到一个让你愣住的答案：**goods plate**。

别笑，真有人这么干过。还有人翻成 goods tray，客户回了个 ❓，他以为客户嫌货不好——客户其实只是想要一个链接。

问题不在你英语差。问题在于：**「货盘」这个词，在英文词典里查不到 1:1 的对应。**它是中文外贸圈自己长出来的黑话。

这篇文章做三件事：把「黑话 → 英文」的对应逻辑讲清楚；把外贸 / 电商 / B2B 最高频的词按生意流程过一遍；再串成几组真实业务句子，你改改就能用。

---

## 一、先解决「货盘」：中文黑话为什么没有英文

先说结论：**「货盘」没有唯一的英文翻译，按语境选词。**

中文里说「货盘」，意思是「你手里能卖的那批货 / 产品集合」。老外不会说 goods plate，他们会根据你的真实意图用不同的词：

| 你真正想表达 | 英文 | 什么时候用 |
|---|---|---|
| 给客户看的产品图册 / 页面 | **product catalog** | 客户说「发我看看有什么货」，发 PDF 或网店链接 |
| 公司产品线全貌 | **product portfolio / product range** | 谈公司实力、介绍业务范围 |
| 电商选品结构、品类搭配 | **assortment** | 运营语境：「我们的选品结构」= our assortment |
| 库存（账册 / 供应链） | **inventory** | inventory level、inventory turnover |
| 现货、马上能发 | **stock** | 「有现货」= in stock，「缺货」= out of stock |
| 可售 SKU 集合 | **SKU mix / available SKUs** | 平台运营、广告选品语境 |

一句话规则：**对外说 catalog / product range，对供应链说 inventory / stock，对运营说 assortment / SKU mix，对战略说 product portfolio。** 客户问「有什么货」用 catalog；仓库问「还有多少」用 stock / inventory。

注意别和物流里的「托盘」搞混——托盘是 **pallet**，叉车用的那个。中文一个「货盘」，英文两个世界。

> 跨境卖家常说的「海外仓货盘」，指的是一批放在海外仓、可本地发货的可售库存，不是一个英文单词。英文里通常直接说 **overseas warehouse stock** / **ready stock**，并说明 **local fulfillment**；不要硬翻成 goods plate，也不必默认等于 dropshipping。**中文黑话往往不是翻译问题，是概念对应问题。**

顺带一提：「货盘」的生命力比英语强——TikTok Shop 半托管火起来之后，行业干脆造了 **goods pool / product pool** 来对应「海外仓货盘」。中文黑话反过来给英语送了新词。但这恰好证明原命题：它是 2023 年之后才被生意需要「逼」出来的概念，不是你能在词典里查到的东西。

有人会说：AI 翻译这么强，还用学？

上面的 goods plate 就是答案。AI 翻得出「货盘」的字面，但判断不了此刻该说 catalog 还是 inventory——**因为那不是一个翻译问题，是一个生意判断：你在跟客户谈产品，还是在跟仓库谈库存？** 招聘市场的门槛也没降：2026 年 3 月北京一家本土轮胎外贸公司的 JD 写明工作语言英语、CET-6 480+ 起步，入职要考开发信写作。AI 把「看懂字」变成了免费品，于是「写得像做生意」反而成了付费项。

## 二、按生意生命周期背词，别按字母表背

背单词最差的方式是按 A–Z。外贸英语更有效的学法是按**生意流程**——每个词都挂在「从我想买到货到手」的某个节点上。

### 阶段 1：找货（货源与选品）

| 英文 | 中文 | 一句话语义 |
|---|---|---|
| sourcing | 找货 / 寻源 | 供应商开发统称，比 buying 更正式 |
| supplier / vendor | 供应商 | 二者常混用；supplier 更通用，vendor 在采购 / 零售侧常见 |
| manufacturer | 制造商 | 强调生产端；贸易商用 trading company |
| OEM / ODM | 贴牌 / 设计代工 | OEM 按你的设计生产；ODM 带设计方案 |
| private label | 自有品牌 | 用你的品牌卖工厂货 |
| specification (spec) | 规格 | 材料、尺寸、公差、色号、包装……询价和质检都靠它 |
| sample / sample order | 样品 / 样品单 | 谈判起点；样品费 = sample fee |
| bulk production | 大货生产 | 相对样品；in bulk = 批量地 |
| prototype | 手板 / 原型 | 比 sample 更早，新产品开发阶段 |

### 阶段 2：谈生意（询盘 → 报价 → 谈判）

| 英文 | 中文 | 一句话语义 |
|---|---|---|
| inquiry / enquiry | 询盘 | 回信常见开场：Thank you for your inquiry |
| RFQ | 询价单 | Request for Quotation，通常带规格、数量、目标交期 |
| quotation / quote | 报价 | quote 可作动词：please quote FOB Shanghai |
| target price | 目标价 | 客户心里的成交锚点；不等于你的底价 |
| counter-offer | 还盘 | 客户还价即 counter-offer；法律上常视为拒绝原报盘并给出新报盘 |
| MOQ | 最小起订量 | 谈判核心筹码；可给 trial order 试单量 |
| lead time | 交期 / 备货生产周期 | **≠ transit time**：lead time 多指下单→货好可发；transit / shipping time = 在途时间 |
| payment terms | 付款条件 | 常见 30% deposit, 70% balance before shipment |
| deposit / balance | 定金 / 尾款 | 收到定金再排产是常见做法 |
| credit terms | 账期 | 30-day credit = 发货后 30 天付款 |
| trial order / repeat order | 试单 / 返单 | 新客户第一单 vs 老客户再下单 |
| key account | 大客户 | KAM = key account manager，常配专属价格与服务 |
| distributor / agent | 分销商 / 代理 | distributor 买断再卖；agent 抽佣、通常不碰货权 |

### 阶段 3：成交（单据与付款）

| 英文 | 中文 | 一句话语义 |
|---|---|---|
| PI (Proforma Invoice) | 形式发票 | 不是税务意义上的正式发票，是交易条件确认 / 客户据以付款的文件 |
| PO (Purchase Order) | 采购订单 | 客户下单文件；卖方内部常对应 Sales Order (SO) |
| commercial invoice | 商业发票 | **清关核心单据之一**，字段缺失或冲突都可能延误 |
| packing list | 装箱单 | 件数、毛重净重、体积、**shipping mark（唛头）** |
| B/L (Bill of Lading) | 提单 | 海运货权凭证；收货人常凭正本提货 |
| C/O (Certificate of Origin) | 原产地证 | 影响税率与自贸协定优惠 |
| T/T | 电汇 | 最常用：T/T 30% in advance, 70% before shipment |
| L/C | 信用证 | 银行有条件付款；单据需与信用证一致，不符点可能导致拒付 |

**Incoterms 2020（必考重点）**：Incoterms 只划分交货义务、风险转移、运费 / 保险等费用由谁承担；**不管付款方式，也不管所有权何时转移**。

- **EXW** 工厂交货——卖方责任最小；货在约定地点交由买方处置，出口手续也常落在买方。海外新人买家拿到 EXW，实务上往往又麻烦又贵
- **FCA** 货交承运人——适合集装箱等现代物流；卖方把货交给买方指定承运人并完成出口清关。**集装箱货优先考虑 FCA，而不是习惯性写 FOB**
- **FOB** 装运港船上交货——**仅适用海运 / 内河**；「FOB Shanghai」仍是海运报价常见写法
- **CFR / CIF**——**仅适用海运 / 内河**。CFR：卖方付运费到目的港，但风险在装运港船上就转移（费用与风险分离，最易被误解）；CIF 比 CFR 多卖方投保
- **DAP** 目的地交货——送到指定地点；进口清关和关税归买方
- **DDP** 完税后交货——卖方责任最大，送到且承担进口清关与关税；B2C 常见 all-in price，但卖方要扛目的国合规与税率风险

口诀：**越靠 D，卖方责任越重、买方越省心；集装箱货慎用 FOB、优先 FCA；新人不轻易碰 EXW 与 DDP 两端。**

### 阶段 4：履约（生产 → 质检 → 物流 → 交付）

| 英文 | 中文 | 一句话语义 |
|---|---|---|
| QC / QA | 质检 / 质量保证 | QA 管体系与过程；QC 管检验与结果 |
| PSI (Pre-Shipment Inspection) | 出货前检验 | 大货离厂前的关键质量闸门 |
| AQL | 可接受质量限 | **不是「允许 2.5% 次品」**，而是抽样检验的统计尺度 |
| ETA / ETD | 预计到达 / 预计离港 | 客户极常问的两个缩写 |
| shipment / shipping | 一批货 / 运输 | shipment = 那票货（your shipment of 500 units）；shipping = 运输这件事 |
| freight forwarder | 货代 | 订舱、报关、拼箱等环节的专业中间方 |
| customs clearance | 清关 | 国际段时效里的高变量 |
| HS code | 海关编码 | 归类决定税率与监管条件；不要图省事乱套通用码 |
| landed cost | 落地成本 | 货价 + 运费 + 关税 + 杂费；做 DDP / 全包价必须算清 |
| LCL / FCL | 拼箱 / 整柜 | 货量不足一柜用 LCL（常按 CBM）；量大用 FCL |
| 3PL | 第三方物流 | 代管仓储、拣货、打包、发货 |
| fulfillment | 履约 | 电商语境常指接单 → 拣货 → 打包 → 发货 |
| dropshipping | 一件代发 | 零售端不囤货，由上游直接发货 |
| last mile | 最后一公里 | 末端配送，通常成本高、体验波动大 |

### 阶段 5：售后（质量与客诉）

| 英文 | 中文 | 一句话语义 |
|---|---|---|
| warranty | 质保 | 书面条款：12-month warranty against manufacturing defects |
| claim | 索赔 | file a claim（提出）；settle a claim（处理 / 结案） |
| return / refund / replacement | 退货 / 退款 / 换货 | B2B 常优先换货，或开 credit note 下次抵扣 |
| rework | 返工 | 验货不合格后的返工处理 |
| corrective action | 纠正措施 | 质量问题常要求供应商出 **CAPA report**（纠正与预防措施报告） |
| RMA | 退货授权 | 先申请 RMA 号再退；无授权可能拒收 |

### 阶段 6：复购（客户运营 + 电商指标）

| 英文 | 中文 | 一句话语义 |
|---|---|---|
| follow up | 跟进 | 外贸很值钱的动作：报价后几天无回复就要 follow up |
| GMV | 成交总额 | 平台流水口径，**常含退款前订单，不等于 revenue** |
| AOV | 客单价 | 销售额 ÷ 订单数；拉高 AOV 是常见利润杠杆 |
| CVR | 转化率 | 下单用户 / 访客（或订单 / 会话）；粗看电商常见大致 1.5–3%，Shopify 均值甚至更低，渠道差异大 |
| CAC / LTV | 获客成本 / 客户终身价值 | 经验健康线 LTV:CAC ≥ 3:1；长期低于 2:1 通常难持续 |
| ROAS | 广告投产比 | 广告带来的收入 ÷ 广告花费；「大约 4:1」只是粗基准，取决于毛利 |
| return rate | 退货率 | 服装常见更高、消费电子更低，品类差极大 |
| cart abandonment | 购物车放弃率 | 行业粗平均常在 70% 左右，意外运费是主因之一 |
| listing | 商品页 / 上架 | 平台运营词：optimize your listing |

## 三、把它们串起来：6 组真实业务句子

### 场景 1：回复客户第一次询盘

> Thank you for your inquiry about our LED strip lights. Please find attached our **product catalog** and **price list** for your review. To prepare an accurate **quotation**, could you share your **target quantity**, key **specifications**, and whether you need **OEM** customization? Our **MOQ** is 500 units, the standard **lead time** is 25 days after **deposit** confirmation, and **samples** can be sent within one week.

译文：感谢您对 LED 灯带的询盘。随信附上产品目录和价目表。为准备准确报价，请告知目标数量、关键规格，以及是否需要 OEM 定制。我们的起订量为 500 件，标准生产周期为收到定金后 25 天，样品一周内可寄出。

*第一封回信四件事：感谢询盘、给 catalog、反问需求（quantity / spec / OEM）、亮 MOQ 与 lead time。*

### 场景 2：报价谈判

> Our **quoted price** is **FOB Shanghai, Incoterms 2020**, based on a **MOQ** of 500 units. If you increase the order to 1,000 units, we can offer a 5% **tiered discount**. This quotation is **valid for 15 days** due to material price fluctuations. Once you confirm, we will issue the **PI** today; payment terms are 30% **deposit** and 70% **balance** before shipment.

译文：我们的报价为 FOB 上海（Incoterms 2020），基于 500 件起订。若订单增至 1,000 件，可给 5% 阶梯折扣。因原材料价格波动，本报价 15 天内有效。确认后今天开具形式发票；付款条件为 30% 定金，70% 发货前付清。

*报价单四要素：单价 + 贸易术语、MOQ、有效期、付款方式。用 valid for X days 给决策窗口，用阶梯价引导加量。*

### 场景 3：催尾款 + 发货通知

> We are pleased to inform you that your order is now **in production** and on schedule. As agreed, the remaining 70% **balance** is due before **shipment**. Once payment is received, we will arrange **customs clearance**, dispatch the goods by **FCL**, and send the **B/L** and **tracking number** shortly after. The **ETA** to Rotterdam is approximately 32 days.

译文：您的订单已在生产且进度正常。按约定，剩余 70% 尾款应在发货前支付。收到款项后，我们将安排清关并以整柜发出，随后发送提单与物流单号。预计抵鹿特丹约 32 天。

*催款不必生硬：先同步进度，再点 balance due，并讲清付款后的下一步。*

### 场景 4：招募海外分销商

> We are looking for an **exclusive distributor** for the UK market with strong retail connections. As a **key account**, you will receive **tiered pricing**, marketing support, and local **stock** support from our UK warehouse to keep **lead times** short. We can start with a **trial order** of 200 units and review the agreement after the first **repeat order**.

译文：我们正在为英国市场寻找具备零售渠道的独家分销商。作为重点客户，您将获得阶梯价格、营销支持，以及英国仓本地库存支持，以缩短交期。可先从 200 件试单开始，首个返单后再复盘协议。

*三个钩子：exclusive、利益结构（价格 + 支持 + 本地库存）、低门槛 trial order。*

### 场景 5：电商运营复盘

> Last month **GMV** grew 18%, but **AOV** stayed flat at $42 and **CVR** dropped from 2.8% to 2.3%, mainly because **cart abandonment** climbed above 70%. Our **CAC** is now $38 while **LTV** is only $96, so the **LTV:CAC** ratio has slipped below 3:1. I suggest we cut the least profitable ads to improve **ROAS**, and add free-shipping thresholds to lift **AOV** and help reduce the **return rate**.

译文：上月 GMV 增长 18%，但客单价仍为 42 美元，转化率从 2.8% 降到 2.3%，主要因购物车放弃率升至 70% 以上。获客成本 38 美元，客户终身价值仅 96 美元，LTV:CAC 已低于 3:1。建议砍掉最不赚钱的广告以改善 ROAS，并用免邮门槛提升客单价、辅助降低退货率。

*复盘基本结构：指标 → 归因 → 动作。LTV:CAC、cart abandonment 用经验区间即可，别当成万能公式；新品期可容忍低于 2:1，这个比率是成熟期的体检指标，不是全周期指挥棒。*

### 场景 6：跟进老客户促返单

> I hope your last **shipment** arrived in good condition and that the **warranty** coverage has been clear on your side. Our new autumn **assortment** is ready — as a **key account**, we can hold current pricing for your **reorder** until Oct 15. If any quality issue comes up, our after-sales team will handle **claims** within 48 hours.

译文：希望上一票货已完好送达，质保条款也清楚可用。秋季新选品已就绪——作为重点客户，您在 10 月 15 日前返单可按现价锁定。如有质量问题，售后团队 48 小时内处理索赔。

*返单跟进：确认上次履约 → 新品 assortment 钩子 → 限时锁价 → warranty / claims 托底。*

## 四、高频易混词速查（新人避坑）

| 容易混 | 区别 |
|---|---|
| lead time vs delivery / transit time | lead time 多指下单到货好可发；transit time 是在途时间；delivery time 较含糊，最好写清起止点 |
| markup vs margin | markup = 加价 ÷ 成本；margin = 毛利 ÷ 售价。$80 成本卖 $100：markup 25%，margin 20% |
| shipment vs shipping | 一票货（名词）vs 运输这件事 |
| inventory vs stock | 高度重叠；stock 更口语、常说 in stock；inventory 更偏账册与供应链管理 |
| catalog vs assortment vs portfolio | 给客户看的目录 vs 选品结构 vs 产品线全貌 |
| OEM vs ODM | 按需方设计代工 vs 供应方带设计 |
| warranty vs guarantee | 产品书面质保条款 vs 更宽泛的保证说法 |
| QA vs QC | 建体系防缺陷 vs 检验抓缺陷 |
| FOB vs CIF | 都属海运术语；CIF 卖方多付运费和保险，风险转移点仍在装运港船上 |
| GMV vs revenue | 流水口径 vs 实际入账营收 |
| distributor vs agent | 买断再卖 vs 抽佣、通常不掌握货权 |
| FCL vs LCL | 整柜 vs 拼箱（常按体积计费） |
| DDP vs DAP | 卖方是否承担进口清关与关税 |
| ETA vs ETD | 到港 / 到仓预计 vs 离港预计 |
| PI vs commercial invoice | 确认条件 / 付款用形式发票 vs 清关用商业发票 |
| AQL vs defect rate | 抽样判定尺度 vs 实际不良率 |
| FOB vs FCA | FOB 是船上交货（海运）；集装箱场景更常更合适的是 FCA |

记不住的先抄这张，可以直接截图：

> 给客户看 → catalog｜仓库还有多少 → stock / inventory
> 集装箱货 → FCA，别惯性 FOB｜卖方责任越靠 D 越重
> 样品 sample、大货 bulk、货权看 B/L
> 流水 GMV ≠ 营收 revenue｜markup 除成本、margin 除售价
> 生意一根线：找货 → 谈单 → 成交 → 履约 → 售后 → 复购

## 五、最后：外贸英语不是词汇表，是商业世界的地图

把上面这些词放在一起看，会更清楚一件事：

**外贸英语首先不是「单词清单」，而是一套商业世界的概念结构。** 你真正学会的不是「lead time = 交货周期」这六个字，而是订单从「我想买」到「货到我手里」中间到底经过哪些节点：找货 → 谈生意 → 成交 → 履约 → 售后 → 复购。英语只是给这些节点贴上对方听得懂的标签。

所以按字母表背单词效率低——词是散的，没有流程这根线。AI 翻译也替不了你做判断——它能给出单词，但不能决定此刻该说 catalog 还是 inventory。

最小行动：**别先背完整词表，直接写这周要发出的第一封开发信或询盘回复。** 对照上面的词和场景句改一版，每用到一个术语，就搞清它在生意里的含义。一封写完，这串词往往就记住了——因为它们本来就长在同一条业务链上。

下次客户再要 catalog，你就知道：他要的不是「货盘」这个中文词，而是你手里那盘货的完整地图。
